# 노랑마을 프로토타입

환경을 정리하고, 얻은 재료로 서식지를 꾸민 뒤, 새 병아리의 도움을 받아 마을 시설을 복구하는 한 구역짜리 플레이 프로토타입입니다.

## 실행

정적 웹 서버에서 `index.html`을 열면 바로 플레이할 수 있습니다.

## 플레이 흐름

1. 마을의 점선 표시 자연물을 눌러 정리합니다.
2. 제작 메뉴에서 `꽃잎 방석`과 `반딧불 등불`을 만듭니다.
3. 만든 물건을 햇살 둥지의 점선 자리에 배치합니다.
4. 새로 찾아온 모루와 함께 끊어진 다리를 고칩니다.

기획서에서 미정으로 남은 행동 에너지, 제작 비용, 환경 경험치 수치는 프로토타입 검증을 위한 임시값입니다.

# 병아리 마을 프로토타입

밝은 아이소메트릭 마을을 직접 정리하고 키우는 모바일 세로형 게임 프로토타입입니다.

## 실행

정적 웹 서버에서 `index.html`을 열면 바로 플레이할 수 있습니다.

## 플레이 흐름

1. 나무, 돌, 풀, 열매 덤불을 직접 눌러 정리하고 재료를 모읍니다.
2. 모은 나무·돌·새싹으로 모닥불, 작업대, 텃밭, 가로등을 짓습니다.
3. 완성된 시설을 눌러 기운을 회복하거나 재료와 행복을 얻습니다.
4. 돌아다니는 병아리를 눌러 함께 놀고, 먹이를 주고, 쉽니다.
5. 오늘의 의뢰를 완료하면 새로운 병아리 주민이 마을에 찾아옵니다.

화면은 390×844 모바일 세로 비율에 맞춰 구성했습니다. 병아리와 미션 이미지는 기존 유니티 리소스를 사용하고, 배경과 상호작용 오브젝트는 게임용 투명 레이어로 새로 제작했습니다.

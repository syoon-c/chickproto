# 병아리 마을 프로토타입

밝은 아이소메트릭 마을을 직접 정리하고 키우는 모바일 세로형 게임 프로토타입입니다.

## 실행

정적 웹 서버에서 `index.html`을 열면 바로 플레이할 수 있습니다.

## 플레이 흐름

병아리 초대부터 자율 생활·직접 교류까지의 현재 임시 규칙과 타임라인은 [GAME_TIMELINE.md](GAME_TIMELINE.md)에 정리했습니다.

1. 병아리가 없는 빈 마을에서 나무, 돌, 풀, 열매 덤불을 채집합니다.
2. 빈 둥지와 주변 자연물·가구를 조합해 서식지를 만들고 하루 동안 돌봅니다. 다음 날 병아리가 찾아올 기회가 생깁니다. 실패하면 다음 방문 확률이 올라갑니다.
3. 찾아온 손님은 둥지에 머뭅니다. 먼저 인사한 뒤 작은 재료 부탁을 들어주면 주민이 됩니다. 새 주민마다 빈 둥지 하나가 필요하며 등장 순서는 고정되어 있지 않습니다.
4. 주민은 시설과 자연물을 찾아다니며 스스로 생활합니다. 행동 중인 병아리를 불러오거나 함께 시간을 보낼 수 있습니다. 좋아하는 가구와 친밀함은 환경 점수에 기여합니다. 건축가 주민과 나무·돌을 모으면 개울 다리를 복구할 수 있습니다.
5. 탐험삐약의 특기와 햇살 숲 수지로 숨은 길을 열고, 풀잎삐약의 특기와 꽃바람 숲 꽃잎으로 꽃밭을 되살립니다. 눈꽃 들판에서는 눈송삐약과 눈 결정으로 얼음 놀이터를 만듭니다. 지역 표지에서 이동합니다.

짓기에서 시설을 고르면 배경의 마름모 칸과 맞춘 설치 격자가 나타납니다. 초록 칸을 눌러 설치하며, 갈색 칸 6곳은 자연물이 자라는 채집 전용 자리라 설치할 수 없습니다. 설치 가능한 칸은 30곳입니다. 이미 설치한 시설은 짓기 화면 아래에서 비용 없이 옮기거나 다른 시설과 자리를 바꿀 수 있습니다. 기운은 다음 날에 회복되고 채집 대상도 지정된 채집 칸에서 다시 자랍니다. 둥지·모닥불·작업대·텃밭·가로등은 채집 재료로 만들고 소풍 탁자·꽃 아치·꽃 그네는 도토리 상점에서 구매합니다. 도토리는 발견 목표를 최초 완료할 때 얻고, 설치한 시설을 개선하는 데도 사용합니다. 환경 레벨 2는 작업대와 새 서식지, 레벨 3은 눈꽃 길 해금 조건에 연결됩니다. 진행 상태는 현재 브라우저에 자동 저장됩니다.
처음부터 체험하려면 가방 아래의 `처음부터 새로 시작`을 두 번 누릅니다.

화면은 390×844 모바일 세로 비율에 맞춰 구성했습니다. 병아리 여섯 종류와 미션 이미지는 기존 유니티 리소스를 사용하고, 배경과 상호작용 오브젝트는 게임용 투명 레이어로 제작했습니다. 소풍 탁자, 꽃 아치, 꽃 그네는 기존 원본에서 게임 화면용으로 쓸 만한 그림이 없어 같은 화풍의 투명 리소스를 새로 보완했습니다.

## 이번 프로토타입의 임시 규칙

원 기획서에서 미정인 수치는 체험을 위해 정했습니다. 기운은 최대 12이고 채집 한 번에 1을 사용합니다. 첫 병아리의 기본 방문 확률은 65%, 이후는 40%이며, 방문에 실패할수록 높아집니다. 첫 병아리는 2번, 이후는 3번 실패하면 다음 유효 판정에서 확정 방문합니다. 환경 레벨은 1~3단계입니다. 이 수치는 밸런스 확정안이 아닙니다. 자세한 규칙과 미결정 사항은 [SYSTEM_PLAN.md](SYSTEM_PLAN.md)에 정리했습니다.

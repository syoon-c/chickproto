# 삐약마을 플레이 프로토타입

모바일 세로 화면용 마을 게임입니다. `index.html`을 열면 새 프로토타입(`village-v2.js`, `village-v2.css`)이 실행됩니다. 이전 버전 파일과 저장 데이터는 삭제하지 않았습니다. 첨부된 플레이 목업과 기획서는 참고자료로 사용했고, 현재 조작 가능한 규칙은 아래와 같습니다.

## 실행

프로젝트 폴더에서 정적 웹 서버를 실행한 뒤 `http://localhost:5173`을 엽니다. 예: `python -m http.server 5173`.

## 플레이 흐름

1. 공터에서 나무·돌·열매 등 지역별 재료를 채집합니다. 채집 장소는 10~45초 후 다시 자랍니다. 작은 밭의 당근은 45초, 조리대의 차·수프는 20초 후 받을 수 있습니다.
2. 생활 가구를 제작해 격자에 놓습니다. 초반 가구는 30~60초, 특수 가구는 3~10분이 걸립니다. 별도로 제작하는 ‘서식지’ 물건은 없습니다.
3. 같은 지역에 서로 다른 기능의 가구를 두 종류 이상 놓고 병아리별 조건을 만족하면, 그 가구 조합이 서식지가 됩니다. 20~50초 안에 병아리가 지역 입구로 찾아오며, 직접 인사해야 마을에 들어옵니다. 인접 칸 배치나 초대 버튼은 필요하지 않습니다.
4. 병아리의 첫 부탁을 들어주면 행복 별이 1개에서 3개로 늘고, 기본 재화 5개와 행복 깃털 2개를 받습니다. 콩이·토리·나루의 부탁에서는 각각 숲 채집·물가 제작·광석 채집에 필요한 능력도 얻습니다. 함께 놀거나 식사하는 활동을 기록하고 후속 이야기를 완료하면 별을 최대 5개까지 올릴 수 있습니다.
5. 주민들의 별 합계가 마을 행복 레벨을 결정합니다. Lv.2에서 숲, Lv.3에서 강변, Lv.4에서 능선이 열립니다. 숲의 향기풀은 꽃 화분, 강변의 갈대는 돗자리, 능선의 광석은 등불 제작에 쓰입니다. 다음 레벨까지 필요한 별은 가방에서 확인할 수 있습니다.

특수 가구 제작에는 기본 재화와 행복 깃털이 쓰여 친구의 부탁 보상이 다음 공간 꾸미기로 이어집니다. 네 지역 배경은 파스텔 색면으로 단순하게 그린 SVG이며 `assets/backgrounds/*-simple.svg`에 있습니다. 18명의 주민과 플레이어는 실제 유니티 프로젝트의 `Assets/98_UI/Sprite/Chick` 원본에서 가져온 서로 다른 그림을 사용합니다(`assets/unity/original/`). 채집물·그네·밭·식탁·조리 시설·등불 등은 프로젝트에 있던 투명 배경 게임 에셋을 재사용하고, 벤치·방석 등 일부 가구는 화면 크기에 맞춘 SVG로 그립니다. 설치 격자와 조작 좌표는 유지하되, 강변 물길의 설치 판정과 등장 위치는 새 배경에 맞췄습니다. 진행 상황은 브라우저의 `chick-village-story-v1` 키에 자동 저장됩니다. 이전에 만든 별도 서식지 물건은 저장 데이터를 불러올 때 제거하고 사용한 재료·재화를 돌려줍니다.

배경에는 잔디 질감과 반복 꽃무늬를 사용하지 않고, 지역별 큰 형태만 남겼습니다. 화면 전체에 채도 필터를 씌우지 않으며, 설치 가구에는 밝은 바닥 받침과 그림자를 적용해 작은 모바일 화면에서도 구분되도록 했습니다. 이전 PNG 배경은 비교용으로 보존했습니다.

입주한 병아리는 가구와 쉼터 사이를 이동하며, 위치는 플레이어처럼 화면 갱신마다 부드럽게 반영됩니다. 제작·방문 등의 게임 시간은 기존대로 처리됩니다.

## 검증

`qa/tempo-smoke.mjs`가 가구만으로 이루어지는 첫 방문, 병아리 인사·부탁·행복 레벨, 네 지역의 가구 조합, 지역별 재료 사용, 지역 간 가구 이동 및 저장·환급을 확인합니다. 기존 `qa/v2-smoke.mjs`는 규칙 변경 전의 기록입니다.

## 아직 단순화된 부분

첨부 목업의 모든 화면을 그대로 재현한 것은 아닙니다. 18명 전체의 후반 영입, 축제, 장식 상점, 병아리별 고유 애니메이션은 추가 검증과 작업이 필요합니다. `GAME_TIMELINE.md`, `SYSTEM_PLAN.md`와 기존 게임 파일은 이전 기획·구현 기록으로 보존되어 현재 규칙과 다를 수 있습니다.

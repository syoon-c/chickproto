# 병아리 마을 프로토타입

밝은 아이소메트릭 마을을 직접 정리하고 키우는 모바일 세로형 게임 프로토타입입니다.

## 실행

정적 웹 서버에서 `index.html`을 열면 바로 플레이할 수 있습니다.

## 플레이 흐름

1. 병아리가 없는 빈 마을에서 나무, 돌, 풀, 열매 덤불을 채집합니다.
2. 첫 빈 둥지와 빈터 정리 조건을 채우고 다음 날을 시작하면 첫 병아리 한 마리가 방문합니다.
3. 새 병아리마다 빈 둥지를 하나씩 더 짓고, 텃밭·환경 레벨·지역 채집 조건을 채워 차례로 맞이합니다.
4. 세 번째 주민인 건축가와 나무·돌을 모아 개울 다리를 복구합니다.
5. 햇살 숲을 채집하면 꽃바람 숲이, 꽃바람 숲을 채집하면 눈꽃 들판이 열립니다. 화면의 지역 표지에서 이동합니다.

짓기에서 시설을 고르면 마을 바닥에 격자가 나타납니다. 초록 칸을 눌러 설치하며, 갈색 칸 6곳은 자연물이 자라는 채집 전용 자리라 설치할 수 없습니다. 설치 가능한 칸은 18곳이고 이미 시설이 놓인 칸에는 다시 설치할 수 없습니다. 기운은 다음 날에 회복되고 채집 대상도 지정된 채집 칸에서 다시 자랍니다. 모닥불, 작업대, 텃밭, 가로등, 소풍 탁자, 꽃 아치, 꽃 그네를 제작할 수 있으며 일부는 설치 후 눌러서 이용할 수 있습니다. 환경 레벨이 오르면 작업대·가로등·꽃 아치·꽃 그네 제작법이 열립니다. 진행 상태는 브라우저에 자동 저장됩니다.
처음부터 체험하려면 가방 아래의 `처음부터 새로 시작`을 두 번 누릅니다.

화면은 390×844 모바일 세로 비율에 맞춰 구성했습니다. 병아리 여섯 종류와 미션 이미지는 기존 유니티 리소스를 사용하고, 배경과 상호작용 오브젝트는 게임용 투명 레이어로 제작했습니다. 소풍 탁자, 꽃 아치, 꽃 그네는 기존 원본에서 게임 화면용으로 쓸 만한 그림이 없어 같은 화풍의 투명 리소스를 새로 보완했습니다.

## 이번 프로토타입의 임시 규칙

원 기획서에서 미정인 수치는 체험을 위해 정했습니다. 기운은 최대 12이고 채집 한 번에 1을 사용합니다. 새 병아리는 빈 둥지와 각자의 조건을 충족하면 다음 날 한 마리씩 확정 방문합니다. 환경 레벨은 1~3단계입니다. 이 수치는 밸런스 확정안이 아닙니다.

# 테마 UI 검토

## 범위

- 화면: 테마 목록, 파츠 가격 상태, 상세 팝업, 구매·적용·보유 상태
- 기준: 사용자가 제공한 유니티 테마 UI 참고 이미지 2장
- 테스트 화면: 480×900, Codex 인앱 브라우저

## 단계별 상태

1. **기본 테마 목록 — 양호**
   - 대표 테이블 아이콘으로 테마를 가로 탐색한다.
   - 파츠 카드는 수익 설명 없이 `가격 / 보유 중 / 적용 중`만 표시한다.
   - 근거: `07-stone-theme-final.png`

2. **미보유 테마 가격 비교 — 양호**
   - 5열 카드에서 파츠별 가격을 빠르게 비교할 수 있다.
   - 테마 이름, 보유 수, 신규 병아리 이름, 구매 진척도가 한 묶음으로 읽힌다.
   - 근거: `06-wood-theme-final.png`

3. **파츠 상세 확인 — 양호**
   - 카드를 눌러야 수익 효과, 누적 수익, 구매 후 수익, 가격과 행동 버튼이 나타난다.
   - 상세 팝업이 열리면 닫기 버튼으로 초점이 이동한다.
   - 근거: `03-part-detail.png`

4. **구매·적용·보유 전환 — 양호**
   - 구매 직후 해당 설비 파츠만 적용되며 다른 설비에는 영향을 주지 않는다.
   - 이전 파츠는 `보유 중`, 현재 파츠는 `적용 중`으로 구분된다.
   - 근거: `04-owned-active-states.png`

5. **메뉴 전환 — 수정 후 양호**
   - 발견 문제: 상세 팝업을 연 채 다른 하단 메뉴로 이동한 뒤 테마로 돌아오면 팝업이 다시 열렸다.
   - 수정 결과: 화면을 벗어나거나 닫힌 메뉴에서 다시 진입하면 선택한 상세 상태를 초기화한다.

## 강점

- 실제 복사된 유니티 아이콘을 사용해 파츠 인지가 빠르다.
- 참고 화면과 같은 5열 밀도와 노란색 적용 상태를 유지한다.
- 기본 카드에서 설명을 덜어내어 가격과 상태가 먼저 읽힌다.
- 버튼에 파츠 이름과 상태가 함께 들어가 스크린 리더용 이름도 구체적이다.

## 남은 접근성 확인 범위

- 200% 확대·고대비 모드·실제 모바일 스크린 리더는 이번 화면 캡처만으로 확인하지 못했다.
- 작은 가격 텍스트는 480px 화면에서는 읽히지만, 저시력 사용자를 위한 확대 테스트가 추가로 필요하다.
